# 深蓝竞技风格 UI 优化

分支：`chore/project-optimization`

本分支重新整理登录页、大厅和牌桌的视觉与布局，统一深蓝配色，扩大牌桌展示空间，并减少提示遮挡和页面滚动。改动集中在页面模板、样式及展示逻辑，保留现有登录流程、游戏规则和下注操作。

## 登录页面

- 使用新生成的德州扑克场景作为全幅背景，登录模块叠加在桌面右侧，窄屏居中显示。
- 页面固定在浏览器窗口高度内，无需上下滚动；按窗口高度压缩标题和模块间距。
- 低于 600px 高的窗口隐藏游戏特色及版本说明，优先完整显示昵称输入框和进入大厅按钮。

## 大厅与牌桌

- 统一深蓝视觉、按钮、房间卡片和信息层级。
- 统一牌桌周围与网页的背景，隐藏冗长的游戏状态诊断区域。
- 桌面牌桌布局适配窗口高度，长操作记录在右侧区域内部滚动。
- 手牌居中放在自己的角色上方；压缩角色卡片，调整多人座位布局。
- 玩家行动提示改为顶部按钮行的文字，只显示最新一条，5 秒后消失，避免遮挡牌型分析。
- 删除左侧重复导航，将游戏大厅和中文 / EN 入口移到顶部按钮行，释放宽度给牌桌。右侧牌型分析、操作记录和个人记录保留。

## 验证

- 通知检查通过：牌桌显示最新一条；旧计时器不会清除新提示；其他页面保留原通知行为。
- 座位展示检查通过：2–9 人座位不重复，自己的角色保持指定位置，玩家顺序不被展示逻辑修改。
- 登录页在 1440×900、1280×720、390×667 和 844×390 视口下无页面溢出，登录按钮完整可见。
- 已在内置浏览器检查登录页和牌桌布局，并重启本地服务加载页面模板。

## 验证边界

布局预览和展示逻辑检查不代表完整多人对局验证。本轮未重新验证端到端登录及完整多人游戏流程；新生成的登录背景是装饰性图片，不显示实时牌局。
